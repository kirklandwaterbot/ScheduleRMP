# Privacy

ScheduleRMP does not collect analytics, create user accounts, or send
data to a server operated by this project.

When a CUNY Schedule Builder page is open, the add-on reads instructor and
college names displayed on that page and sends those values directly to Rate My
Professors to find a public rating and profile. Results and user preferences are
stored locally in Firefox. Cached results can be cleared from the add-on popup.

When the user chooses calendar export, ScheduleRMP locally reads the currently
visible course names, dates, times, locations, sections, and related schedule
details. It uses those details only in memory to preview and create a local
`.ics` file. Schedule details are not sent to Google, Rate My Professors, or a
server operated by this project.

Rate My Professors receives requests according to its own privacy policy. This
project is unofficial and is not affiliated with CUNY or Rate My Professors.
